## 4. 样本限制披露（协议 §0.1 / 报告口径）

以下为**招募阶段即可确定**的限制，须在技术报告中如实披露，不得等到结论阶段再补：

| 限制 | 事实 | 对结论的影响 |
|---|---|---|
| **样本量** | 3 人，为协议规定的**下限** | 只支持初步可用性判断，**不能推断广泛市场效果**；低于 3 人则只能作个案记录、不进统计 |
| **经验分布偏低** | 三人分别画过 **1 / 1 / 2 块板**；两人仅有一块 | 样本以**新手为主**。结论适用范围限于经验较浅的 KiCad 使用者；不得外推到资深硬件工程师 |
| **打样比例未知** | 三人是否打过样均为 TODO | 「画过板」与「打样并回件调试过」是不同的经历深度，影响其踩坑经验的丰富度，访谈时须补记 |
| **专业背景集中** | 三人及第 4 位联系人均为**人工智能 / 物联网及相关专业**的在校学生 | 结论适用范围限于**相关专业学生**，不得外推至职业硬件工程师或其他学科背景的使用者 |
| **实验室聚集** | 三人来自**完全不同的实验室，且互不认识** | **这一点对样本有利**——不存在同一工作流 / 同一套习惯造成的聚集污染，三人的经验相互独立 |
| **自我选择偏差**（推断，非受访者陈述） | 第 4 位联系人的婉拒理由之一是「觉得自己不能胜任」 | **接受邀请的三人可能系统性地比总体更自信**。该推断来自拒绝理由，非受访者自陈；报告中须作为方法学限制披露，不得因样本表现良好而略去 |
