## 三、设计要点记录

1. MCU 采用 **ESP32-C3-WROOM-02-N4**（C2934560）：换型自 MINI-1，因 KiCad 官方符号/封装齐备可全自动流水。
2. I2C 上拉走 **IO4/IO5**：避开 GPIO8/9 strapping 脚冲突（GPIO9 留给 BOOT 按键），该冲突在意图阶段即被拦截。
3. USB-C CC1/CC2 各 5.1k 下拉；LDO ME6211C33（500mA）USB 5V→3.3V；SHT30 地址脚接地=0x44。
4. 工艺约束：线宽 ≥0.15mm（首选 0.2）/ 间距 0.18mm / 最小钻孔 0.2mm——嘉立创经济工艺裕量内。

## 四、已知限制与遗留项

0. **当前硬阻断**：必须在 intent/原理图生成源中补齐 +5V/GND 电源驱动语义并重新获取 G2 ERC 0；同时完成 `docs/M2板级工程评审.md` 的 8 项人工评审。禁止编辑 ERC JSON 伪造通过。

1. **固件框架已迁移至 ESP-IDF 6.0.1**（原 Arduino 版因 Wokwi×C3 应用层串口不可捕获而弃用）。迁移后 G9 断言全绿：`{"seq":1,"t_c":25.10,"rh":51.0}` 命中。
2. **仿真传感器为桩**（SIM_STUB_SENSOR）：Wokwi CLI 注册表无 SHT31 零件，行为断言验证的是"固件管线/JSON/时序"（A 级）；I2C 协议层由 host 单测覆盖（A 级）；真实传感器读数待上板实测（C 级）。
3. **无实物验证**：上电、BLE 距离、功耗等 C 级项目待打板回件后人工实测。
4. freerouting 匿名遥测在墙内环境拖住进程，已用 Java 代理参数拦截（tools 内链式命令已内置）。

## 五、复现命令

```powershell
# 原理图链
py -3 gates\run_gates.py
akcli ops from-intent src\hardware\m2-board\intent_v1.json -o src\hardware\m2-board\ops_gen.json
akcli draw <sch> --ops ops_gen.json --apply --strict-nets
# PCB 链
<CadPython> tools\build_board.py; <CadPython> tools\dsn_ses.py export ... ; java -jar tools\bin\freerouting-2.3.0.jar -de in.dsn -do out.ses -mp 10 -mt 1 ; <CadPython> tools\dsn_ses.py import ...
kicad-cli pcb drc --format json --output g4.json <pcb>
# 固件链
pio run -e esp32c3 -e esp32c3_simstub -d src\firmware
pio test -e native -d src\firmware --filter test_sht30
```
