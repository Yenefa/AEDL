## 三、设计要点记录

1. MCU 采用 **ESP32-C3-WROOM-02-N4**（C2934560）：换型自 MINI-1，因 KiCad 官方符号/封装齐备可全自动流水。
2. I2C 上拉走 **IO4/IO5**：避开 GPIO8/9 strapping 脚冲突（GPIO9 留给 BOOT 按键），该冲突在意图阶段即被拦截。
3. USB-C CC1/CC2 各 5.1k 下拉；LDO ME6211C33（500mA）USB 5V→3.3V；SHT30 地址脚接地=0x44。
4. 工艺约束：线宽 ≥0.15mm（首选 0.2）/ 间距 0.18mm / 最小钻孔 0.2mm / 最小过孔 0.4mm（J1 舌片 0.5mm 节距逃逸专用）——嘉立创经济工艺裕量内。
5. USB 差分对：J1 舌片焊盘手工扇出（DM 双 0.4/0.2 小过孔 B.Cu 汇合、DP F.Cu 中柱），DM 加 0.55mm 蛇形凸包，skew 0.87mm（要求 <=1.0mm）。

```powershell
# 一键门禁（当前 7/7 PASS，exit 0）
py -3 gates\run_gates.py
# 板级评审证据（8 项机器实测）
py -3 tools\board_review.py
# 当前环境未验证 akcli；恢复后才可重新生成并重放当前 M2 ops。
# PCB 链
<CadPython> tools\build_board.py  # 建板+功能布局+J1 舌片手工扇出
<CadPython> tools\dsn_ses.py export src\hardware\m2-board\m2_board.kicad_pcb src\hardware\m2-board\m2_board.dsn
java "-Dhttp.proxyHost=127.0.0.1" "-Dhttp.proxyPort=1" "-Dhttps.proxyHost=127.0.0.1" "-Dhttps.proxyPort=1" -jar tools\bin\freerouting-2.3.0.jar -de src\hardware\m2-board\m2_board.dsn -do src\hardware\m2-board\m2_board.ses -mp 10 -mt 1
<CadPython> tools\dsn_ses.py import src\hardware\m2-board\m2_board.kicad_pcb src\hardware\m2-board\m2_board.ses
kicad-cli pcb drc --format json --output g4.json <pcb>
# 交付链（gerbers/钻孔/贴片坐标 + zip 打包）
kicad-cli pcb export gerbers --output delivery\gerbers <pcb>
kicad-cli pcb export drill --output delivery\gerbers <pcb>
kicad-cli pcb export pos --format csv --output delivery\pos.csv <pcb>
Compress-Archive -Path delivery\gerbers\* -DestinationPath delivery\jlc_gerber_upload.zip -Force
# 固件链
pio run -e esp32c3 -e esp32c3_simstub -d src\firmware
pio test -e native -d src\firmware --filter test_sht30
```
