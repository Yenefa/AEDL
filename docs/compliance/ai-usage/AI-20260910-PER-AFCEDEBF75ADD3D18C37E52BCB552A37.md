### 2026-09-11 更正（回应 Yenefa 对 PR #59 的 REQUEST_CHANGES）

**v1.0 的 §2.2 裁决「访谈逐字记录……可随仓库公开」是错的，已撤回。** 原句不改写，更正记于此。

**错在哪**：参与者实际授予的 disclosure scope 是「private repository 存储 + 汇总对外」——
协议 §1.2 的口头原话是「原始记录只存在我自己的电脑和这个学生竞赛项目的**私有仓库**里，
竞赛材料中只出现**汇总结果**」；§8.1 勾选项写「存储位置：个人电脑 + 项目**私有** GitHub 仓库；
**仓库公开前将再评估**是否需要进一步脱敏」。

**「再评估」是重新评估的承诺，不是预先授予的发布许可。** 把 pseudonymized 逐字记录放到
全球可见的 GitHub，构成**新的 disclosure scope**，不在原同意范围内。v1.0 把「再评估」
读成了「评估后即可发布」，这是对一项向真人作出的承诺的单方面扩张。

**本条错误的性质**：协议 §1.2 与 §8.1 的那两段承诺文本**由本 Agent 在 E5 协议 v1 中起草**，
v1.0 又写出与之冲突的裁决——即自行推翻了自己写下、并已由 Percy 口头告知给三名参与者的承诺。
记录于此以明确该错误不属于"理解上游文档有歧义"，而属于未回查自己作出的承诺。

**内部矛盾**：v1.0 的 §2.4 自述「一旦公开，撤回无效」「E5 会话记录在转 public 之前应视为
可能需要撤回的内容」，与同一文件 §2.2 的「可随仓库公开」直接冲突。审查者指出了这一点，属实。

**v1.1 的更正**：
