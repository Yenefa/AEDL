### 本次改动

- `gates/repair_verification.py`（+293 行）：新增 `toolchain_manifest()` / `fresh_export()` / `bind_inputs()`。
  - `fresh_export`：固定命令 `kicad-cli sch export netlist --format kicadxml`（argv 来自宿主 toolchain manifest），`shell=False`；输出目录必须是本次新建（残留即 `BLOCKED / REPAIR_EXPORT_STALE`，**旧 XML 永不复用**）；记录 source 在导出前／导出后／解析结束三个 SHA256，任一不等即 `FAIL / REPAIR_SOURCE_UNBOUND`；exit≠0 → `TOOL_ERROR`；exit=0 但无文件、空文件或不可解析 XML → `FAIL`（exit=0 不等于成功）；二进制缺失／digest 变化 → `TOOL_ERROR / REPAIR_TOOL_UNAVAILABLE`；版本非 10.0.5、argv 被改、超时上限被放宽均 fail-closed。`ExportProof.completed` 只在「exit=0 且 XML 可解析且三个 hash 相等」时为 true；失败路径也返回 proof 供回执取证。
  - `bind_inputs`：逐字节重算 snapshot／stage manifest（大小 + SHA256 + 目标唯一性），重算 `bound_policy_sha256`（`canonical_sha256("policy-bound", …)`）与 toolchain digest，不匹配即 `BLOCKED / REPAIR_INPUT_DRIFT`；路径按声明根做严格包含检查，并拒绝链接／reparse point。
- `tests/test_repair_verification.py`（+230 行）：新增 `FreshExportTests`（9 例），用宿主提供的桩 CLI 覆盖 C3-P1／P2／P3／P5／P7 的软件语义与路径逃逸拒绝。桩是测试本地文件，不读任何 fixture，生产模块未留后门。
