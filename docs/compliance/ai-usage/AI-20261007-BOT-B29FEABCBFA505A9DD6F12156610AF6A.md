- `baseline_generic.json`：schema 里**没有** `in_scope_*` 字段；同目录的

- `render()` 把未执行打成 `primary 0/5`，与"跑了但没通过"在文本上完全同形。

### 修法

1. **一次运行一个目录**：`allocate_run_dir()` 生成
   `<UTC 时间戳>-<arm>-<代码 sha7>-<序号>`；`write_receipt()` 遇同名文件抛 `RunCollision`，
   绝不覆盖。`main()` 默认走分配路径，`--out` 为本次运行目录、`--runs-dir` 为父目录。
2. **回执自证出身**：新增 `provenance` = run_id / 起止时间 / 代码 sha+branch+dirty /
   python 与解释器路径 / 写入器身份（存在则 path+sha256，缺失则 `NOT_RUN` + 含 `AKCLI=` 的
   行动指引 + 试过的路径）/ 模型 host+model（**密钥不进回执**，测试直接断言）/
   四个输入哈希（合同、episode 清单、structural oracle、**夹具清单 `manifest_v1.json`**）/
   预算起止快照。
3. **"没跑成"与"没通过"分开**：每条 episode 增加 `verdict ∈ {pass, fail, not_executed}`
   （primary / regression / structural 三个口径**逐字不动**），summary 单列 `not_executed`；
   纯函数 `control_findings()` 落实 `episodes_v1.json` 自己写的控制规则
   （noop 不得通过、oracle 必须达 PASS、全未执行即不可报告），
   报告新增 `reportable` / `unreportable_reasons`，`render()` 打 `NOT EXECUTED` 与
   `REPORTABLE: no`，`main()` 对不可报告返回**退出码 3**。
4. **旧证据不改动**：平面文件原位保留，新增 `runs/README.md` 说明新旧布局、
   并明确写出"`RESULTS_20261005.md` 与 `EVIDENCE_INDEX.md` 引用这些文件的数字不可复核、
   自本卡合并起待重跑"（依 §0A.5 第 5 条，不删不改写）。
