## 0. 一句话范围

对 **M2 载板（唯一主案例）的原理图**，本期仅支持「信号接线关系」「已核实器件参数」两类
受约束修复；每处修复必须走 **受约束补丁通道 → 独立 KiCad 重验 → 证据留痕** 的闭环；
**零覆盖不算通过**。

## 1. 支持的修复类别（仅此两类）

### 1.1 信号接线关系

- **定义**：网络连接与工程意图不符——网络名/引脚映射/差分对身份错误，或信号路径要求缺失
  （串阻、上拉/下拉、去耦/储能电容缺件）。
- **W1 六案例中属此类**（P4 独立期望值为准）：
  - USB D+/D- 身份接反（PIT-20260830-001）
  - 缺 USB 22Ω 串阻
  - 缺 GPIO9 10kΩ 上拉
  - 缺 EN 1µF 电容
- **边界**：只改 `.kicad_sch` 内的连线/网络/元件存在性与元件值表达；每处修复须有
  P3 器件事实目录或官方数据手册页码支撑，无出处不修。

### 1.2 已核实器件参数

- **定义**：元件参数/配置与已核实事实（数据手册、应用笔记）不符——阻容值、地址配置、
  封装映射等。
- **W1 六案例中属此类**：
  - SHT30 ADDR 悬空 vs 固件写死 0x44（跨硬件↔固件一致性，重点案例）
- **边界**：「已核实」的门槛 = P3 器件事实目录中带**页码**的原文摘录；核不到 →
  一律 UNKNOWN / 拒绝修复，不脑补、不引用社区二手数据。

### 1.3 修复执行通道（唯一合法通道）

- akcli 0.21.0 受约束补丁：strict-nets 开启（合网拒绝）；写入三重核对
  （`applied` 字段 + 重新读取 + 字节哈希）；回滚用**固定快照**，不依赖 undo。
- 通道之外的一切写入方式（手改文件、脚本直写、AI 直出完整文件）**不算有效修复**，
  不得计入任何指标。

### 1.4 验证通道（独立性约束，ADR-008）

- 修复写入后必须用**独立的** KiCad 原生解析/导出/ERC 重读验证；
  compiler 与 verifier 不得只消费同一份数据互相证明。
- Percy 侧 KiCad 10.0.5 独立环境（ERC 冻结证据已复现）作为第二套交叉核对环境
  （E4 复现数据点）。

## 3. 判定结果语义（六态，全链统一）

| 状态 | 定义 | 计入成功？ |
|---|---|---|
| `PASS` | 修复写入 → 独立 KiCad 重验通过 → 有器件事实/手册页码支撑 | ✅ |
| `FAIL` | 修复写入但独立重验不通过，或引入新错误 | ❌ |
| `UNKNOWN` | 证据不足无法判定（如缺资料） | ❌ 零覆盖 |
| `NOT_RUN` | 未执行（如实标注，不得事后补写） | ❌ 零覆盖 |
| `TOOL_ERROR` | 工具链故障（非设计问题），须留存错误证据 | ❌（须与 FAIL 区分） |
| `NOT_APPLICABLE` | 案例不属于本期两类修复范围 | ❌ 零覆盖 |

**零覆盖不算通过**：`UNKNOWN` / `NOT_RUN` / `NOT_APPLICABLE` 一律不计入成功数；
不得把缺资料包装成 PASS。

**「正确拒绝」是卖点不是失败**：对资料不足的修复请求（W1 案例 6：U3 资料不足），
正确输出 = `NOT_APPLICABLE`/`UNKNOWN` + 拒绝理由 + 缺失证据清单（package / pin mapping /
operating voltage 等）。这证明系统懂边界，直接回应评分项「错误拒绝率/假通过」。

## 4. 实验与指标边界

### 4.1 E2 主指标（冻结验收口径，评分 S4/E2）

**完全满足冻结验收、且没有新增错误的修复数**。同时必须报告调用成本、耗时与失败，
不得只统计「模型输出了补丁」。

### 4.2 AI 解释价值维度（大统领 2026-09-06 增补，进 Y4 与后续全部对比实验）

不只比较「AI vs 脚本谁修复成功」，增测 **AI 解释价值**：

- 脚本输出裸信号：`ERROR: net mismatch`；
- AI 应输出把工程事实矛盾讲清楚、人能理解、能执行的修复路径，例如：
  `USB differential pair swapped because: datasheet pin mapping / schematic net /
  firmware configuration contradict`（三者对照定位 + 建议动作）。

**价值假设**：AEDL 的 AI 价值可能不是「替代规则」，而是**把工程事实转化为人能理解、
能执行的修复路径**。该维度由 **Percy 独立评审**（验收侧），评审时与修复成败分开记录，
不因单一维度下结论。解释质量的最低门槛：指认矛盾双方、给出可执行动作、无凭空事实
（每条解释可回溯到器件事实目录或手册页码）。

### 4.3 Y4 止损闸门联动

若 W1 结论为「脚本覆盖全部 6 例」，则 AI 承担任务与创新表述随之调整
（AI 角色收缩为解释与定位，机械修复交脚本），本冻结文档出修订版并重走交叉复核。
