## 3. 本轮 DRC 收敛记录（2026-08-29）

重建布局 + freerouting 重布线后，从 5 条违规收敛到 0：

1. **过孔直径 x3（0.4mm < 板级 0.6mm 约束）**：舌片 0.5mm 节距走廊放不下 0.6mm 过孔，板级最小过孔放宽到 0.4/0.2（`m_ViasMinSize`，与 `.kicad_pro` 同步），属常规 2 层板工艺能力内。
2. **CC2 过孔与 USB_DP 净距 0.10mm（需 >=0.18）**：CC2 过孔移位至 (46.45,3.15)，距 DP 汇合横线端点 0.78mm、距 +5V 过孔 0.87mm。
3. **USB_DM B.Cu 悬空走线**：深回廊改为两小过孔 B.Cu 直连（中心距 1.0mm，边缘净距 0.6mm），无悬空端。
4. **freerouting 残留单层连接过孔 x1（+3V3 @ 4.50,12.21）**：三条关联走线全在 F.Cu，过孔冗余，删除后端点重合保持连通。
5. **USB 差分 skew 1.97mm 超标**：USB_DM F.Cu 长直段 (20.75,18)→(35.74,18) 加 +0.55mm 蛇形凸包（x∈[26,33] 走廊无其他铜），skew 收敛到 0.87mm；铺铜重灌。
