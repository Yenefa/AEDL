## 1. 问题本质（为什么 1A 额定不等于解决问题）

线性稳压器的芯片耗散不能只算“压差×负载电流”。本轮按更保守的
`P_D = (V_IN - V_OUT) × I_OUT + V_IN × I_Q(max)` 核算；AMS1117 原厂表给出固定版
`I_Q(max)=11mA`。冻结输入如下：

- `V_IN=5.0V`、`V_OUT=3.3V`（**仅为标称输入筛查点**，不是最终输入上下限合同）。
- `I_OUT=150mA`：项目“周期采集”持续负载假设，仍需整板实测确认。
- `I_OUT=345mA`：仓库冻结的 U1 datasheet v1.7，第 6.4.1 节 / PDF 第 23 页，
  802.11b 1Mbps @20.5dBm、100% duty cycle 的 TX 峰值。该值仅代表 U1，**尚未包含其他 3V3 负载**。
- 因此 `P_D(150mA)=0.310W`，`P_D(345mA)=0.6415W`。v1 的 255mW/595mW
  分别漏掉了静态电流项，并把 345mA 四舍五入成 350mA，只能视为早期粗筛值。

|---|---|---|
| 现 U3 C235316（SC-70-5） | 仅负载项已达 255mW，超过其绑定版 V20 的 250mW@25°C 硬边界 | **BLOCKED** |
| B2 类：1A SOT-23-5 LDO | 未冻结具体料号、θJA 与安装条件 | **不能定量判定** |

| B3：DC-DC buck | 本提案未完成具体料号、纹波、BOM 与布局核实 | `TO_VERIFY` |

### 1.1 ADR-005 温度分档核算（25/60/85°C）

原厂规定连续正常负载下 `Tj≤125°C`，并明确实际 θJA 取决于 PCB 铺铜与附近热源。
下表按 ADR-005 的 **25/60/85°C** 三档计算；55/60/65°C/W 是原厂表 1 的示例安装结果，
90°C/W 是 SOT-223 名义值，均不能替代本板布局实测：

| 负载工况 | θJA 假设 | P_D | ΔT | Tj@25°C | Tj@60°C | Tj@85°C | 判定 |
|---|---:|---:|---:|---:|---:|---:|---|
| 150mA 项目假设 | 90°C/W | 0.310W | 27.9°C | 52.9°C | 87.9°C | 112.9°C | 数学不过限；负载仍待整板确认 |
| U1 345mA TX | 90°C/W | 0.6415W | 57.7°C | 82.7°C | 117.7°C | **142.7°C** | **85°C 档失败** |
| U1 345mA TX | 65°C/W | 0.6415W | 41.7°C | 66.7°C | 101.7°C | **126.7°C** | **85°C 档失败** |
| U1 345mA TX | 60°C/W | 0.6415W | 38.5°C | 63.5°C | 98.5°C | 123.5°C | 仅低于上限 1.5°C，不能称“裕度充足” |
| U1 345mA TX | 55°C/W | 0.6415W | 35.3°C | 60.3°C | 95.3°C | 120.3°C | 仅低于上限 4.7°C，仍需实板证据 |

- 在 `V_IN=5.0V`、`I_OUT=345mA` 的筛查点，85°C 档若只要求不超过 125°C，需
  `θJA≤(125-85)/0.6415=62.4°C/W`；这尚未给其他 3V3 负载、器差、测量误差和热耦合留余量。
- 最终 ECO 必须用实际 `V_IN,max` 与整板 `I_OUT,max` 重算，并把 SOT-223 tab 铺铜面积、层叠、铜厚、
  热过孔及相邻热源绑定到 PCB 版本；回件后测温。原厂表 1 只能作布局目标，不能冒充本板 θJA。
- **修订结论：大封装/铺铜是必要条件，不是充分条件。B1 在 85°C 档尚未获得热放行，
  “双工况均可行、裕度充足”撤销。**

### 2.1 输出电容稳定性合同（P1 复核修订）

原厂 datasheet 的 Stability 章节明确：输出电容属于频率补偿的一部分，输出端使用
**22µF 固体钽电容可保证全部工作条件下稳定**；无 ADJ 旁路时较小电容可能可用，但原文
没有给出“10µF X5R 陶瓷可保证稳定”的合同，也没有给出可直接照抄的陶瓷 ESR 窗口。

当前 BOM 为 C2=`10µF/25V X5R 0805`（C15850），C3/C4 各 100nF。它们是当前板事实，
**不是 AMS1117 稳定性已满足的证据**。ECO 必须二选一并失败关闭：

1. **原厂保证路径**：在 U3 输出端采用 22µF 固体钽电容；ECO 时冻结精确 MPN、额定电压、
   降额、极性、封装和摆放，并同步 BOM/原理图/PCB/极性门禁。当前提案不代选具体电容料号。
2. **偏离原厂保证路径**：若保留 10µF X5R 或改用其他 MLCC/聚合物，必须冻结精确料号，
   给出 DC Bias/温度下有效电容与厂商稳定性依据，并在 `V_IN,min`、标称输入、实际最小负载、
   150mA 与 345mA/整板最大负载及 25/60/85°C 条件下做启动和负载阶跃实测。验收至少要求：
   3V3 保持在 U1 的 3.0~3.6V 工作范围、无持续振荡、无复位，并留存示波器原始波形。

在上述任一路径完成前，**Cout 稳定性状态 = BLOCKED**；静态 ERC/DRC 或电容标称值相加不能放行。

### 2.2 最低输入工况（P1 复核修订）

原厂数据只证明 800mA 时 dropout 为 typ 1.1V / max 1.3V，并说明低电流时下降；它没有给出
345mA 的保证最大值。故不能把标称 `5.0V-3.3V=1.7V` 直接写成“满足余量”。

本项目把最低输入定义在 **U3 VIN 引脚/焊盘**，记为 `V_IN_U3,min`，而不是 USB 电源标称值。
当前尚未冻结电源源端下限、线缆、连接器/保险器件、走线压降和瞬态下陷，故这些量一律
`TO_VERIFY`；rev2 中未经来源绑定的“4.75V VBUS 下限”和“0.05~0.15V 线损”不作为结论。

- 保守静态筛查线：`V_IN_U3,min ≥ 3.3V + 1.3V = 4.60V`。1.3V 取原厂 800mA 保证最大值，
  用于失败关闭，不把曲线典型值内插成 345mA 的保证值。
- ECO 验收必须在最差允许电源/线缆组合下，同时捕获 U3 VIN 与 3V3：上电、U1 100% duty TX、
  负载阶跃和整板最大负载均须覆盖；`V_IN_U3,min` 不得低于 4.60V，3V3 须保持 3.0~3.6V，
  且供电能力须满足 Espressif 官方建议的 **不低于 500mA**。
- 若任一条件失败或实际源端下限仍未知，则 **B1 输入余量状态 = BLOCKED**；应改电源路径或
  重新选型，不能用“标称 5V”覆盖未知压降。

## 3. ECO 影响面（比上次换料大，如实列出）

1. **封装不兼容**：SOT-353 → SOT-223 引脚完全不同（AMS1117：1=GND 2=VOUT 3=VIN tab=VOUT，
   `TO_VERIFY` 冻结 datasheet 核对）——**不是**上次那种逐脚兼容替换，原理图 symbol、PCB
   footprint、逃逸布线、courtyard 全部重做。
2. **board_review 关键字陷阱（PIT 防复发）**：`tools/board_review.py` 的热源/极性/去耦检查
   按 lib_id 关键字识别 U3（上次补过 `SOT-353`）——**换 SOT-223 必须同步补关键字**，
   否则 U3 从三项检查中静默消失（变相放水，禁止）。
3. 全链同步清单（同上次 SOP）：intent → BOM → 原理图 → PCB footprint/布线 → DRC →
   ops 重放 → delivery 重导 → 需求合同重签（语义哈希联动）→ 渲染证据重生成 →
   board_review_auto 重新冻结。
4. U1 冻结 datasheet v1.7 已核得 TX 峰值 345mA；ECO 仍须把其他 3V3 负载计入整板最大电流，
   并以实际 `V_IN,max` 重跑热表。
