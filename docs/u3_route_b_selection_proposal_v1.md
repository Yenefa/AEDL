## 1. 问题本质（为什么 1A 额定不等于解决问题）

功耗耗散由压差×电流决定，与芯片电流额定无关：

- 目标场景（周期采集）：持续负载 ≈ 150mA → P = 1.7V × 0.15A = **255mW**
- 热设计工况（持续 WiFi 发射，量级参考 U1 datasheet，精确值 `TO_VERIFY`）：≈ 350mA → P = **595mW**

| 现方案/候选 | 封装 | θJA（`TO_VERIFY` 待冻结原件核对） | 255mW 时 ΔT | 595mW 时 ΔT | 结论 |
|---|---|---|---|---|---|
| 现 U3 C235316（SOT-353） | SC-70-5 | ~350°C/W 量级 | +89°C → **Tj≈140°C > 125°C absmax** | 更糟 | **热不可行**（V20 Pd absmax 250mW@25°C，255mW 已越界） |
| B2 类：1A SOT-23-5 LDO | SOT-23-5 | ~250°C/W 量级 | +64°C → Tj≈114°C@Ta50 | **+150°C+ → Tj>200°C，不可行** | **595mW 工况下热不可行**——1A 额定救不了 SOT-23-5 |
| **B1：AMS1117-3.3（C6186）** | **SOT-223** | **~90°C/W** | +23°C → Tj≈73°C@Ta50 | **+54°C → Tj≈104°C@Ta50 < 125°C** | **双工况均可行，裕度充足** |
| B3：DC-DC buck | 多器件 | — | 极低 | 极低 | 热最优，但 BOM/布局/纹波验证成本最高，150mA 场景过设计 |

**核心结论：热问题的解在封装（θJA），不在电流额定值。** 只有换到大面积散热焊盘封装
（SOT-223 带散热 tab）才同时满足持续 150mA 与 350mA 工况。

## 3. ECO 影响面（比上次换料大，如实列出）

1. **封装不兼容**：SOT-353 → SOT-223 引脚完全不同（AMS1117：1=GND 2=VOUT 3=VIN tab=VOUT，
   `TO_VERIFY` 冻结 datasheet 核对）——**不是**上次那种逐脚兼容替换，原理图 symbol、PCB
   footprint、逃逸布线、courtyard 全部重做。
2. **board_review 关键字陷阱（PIT 防复发）**：`tools/board_review.py` 的热源/极性/去耦检查
   按 lib_id 关键字识别 U3（上次补过 `SOT-353`）——**换 SOT-223 必须同步补关键字**，
   否则 U3 从三项检查中静默消失（变相放水，禁止）。
3. 全链同步清单（同上次 SOP）：intent → BOM → 原理图 → PCB footprint/布线 → DRC →
   ops 重放 → delivery 重导 → 需求合同重签（语义哈希联动）→ 渲染证据重生成 →
   board_review_auto 重新冻结。
4. U1 datasheet 峰值电流（350mA 量级）以冻结原件核对后回填热核算表。
