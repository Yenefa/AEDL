## 1. 问题本质（为什么 1A 额定不等于解决问题）

功耗耗散由压差×电流决定，与芯片电流额定无关：

- 目标场景（周期采集）：持续负载 ≈ 150mA → P = 1.7V × 0.15A = **255mW**
- 热设计工况（持续 WiFi 发射，量级参考 U1 datasheet，精确值 `TO_VERIFY`）：≈ 350mA → P = **595mW**

| 现方案/候选 | 封装 | θJA（`TO_VERIFY` 待冻结原件核对） | 255mW 时 ΔT | 595mW 时 ΔT | 结论 |
|---|---|---|---|---|---|
| 现 U3 C235316（SOT-353） | SC-70-5 | ~350°C/W 量级 | +89°C → **Tj≈140°C > 125°C absmax** | 更糟 | **热不可行**（V20 Pd absmax 250mW@25°C，255mW 已越界） |
| B2 类：1A SOT-23-5 LDO | SOT-23-5 | ~250°C/W 量级 | +64°C → Tj≈114°C@Ta50 | **+150°C+ → Tj>200°C，不可行** | **595mW 工况下热不可行**——1A 额定救不了 SOT-23-5 |
| **B1：AMS1117-3.3（C6186）** | **SOT-223** | **~90°C/W** | +23°C → Tj≈73°C@Ta50 | **+54°C → Tj≈104°C@Ta50 < 125°C** | **双工况均可行，裕度充足** |
| B3：DC-DC buck | 多器件 | — | 极低 | 极低 | 热最优，但 BOM/布局/纹波验证成本最高，150mA 场景过设计 |

### 1.1 ADR-005 温度分档核算（B1 = AMS1117-3.3，θJA ≈90°C/W `TO_VERIFY`）

按 ADR-005 的分档口径：Tj = Ta + P×θJA，Ta 分 25/40/50/60°C 四档，负载分 150mA（周期采集）
与 350mA（持续 WiFi 发射，量级 `TO_VERIFY` 待 U1 冻结原件核对）两档：

| 工况 | 耗散 | ΔT=0.9°C/mW×P | Ta=25°C | Ta=40°C | Ta=50°C | Ta=60°C |
|---|---|---|---|---|---|---|
| 150mA 持续 | 255mW | +23.0°C | 48.0°C | 63.0°C | 73.0°C | 83.0°C |
| 350mA 持续 | 595mW | +53.6°C | 78.6°C | 93.6°C | 103.6°C | **113.6°C** |

- 绝对上限 125°C（AMS1117 工作上限，`TO_VERIFY` 冻结 datasheet 核对）：各档均不越界。
- **工程裕度判定（ADR-005 口径：距上限建议 ≥20°C）**：Ta≤50°C 时两档负载全部满足；
  **Ta=60°C 档 + 持续 350mA 工况裕度仅 11.4°C，不满足建议裕度**——该组合须限幅
  （占空比约束/软件热保护）或按实测 θJA 重核后放行。周期采集场景（150mA 档）四档全过。
- θJA 非 90°C/W 时的敏感度：θJA 每高 10°C/W，595mW 工况 Tj 再升 6°C——冻结 datasheet
  与 PCB 铜厚/铺铜面积核算是 ECO 第一步，结论以此为终审。

**核心结论（证据边界内）：在本次已核实的候选中，热问题的解在封装（θJA），不在电流额定值。
只有带散热焊盘的封装（SOT-223 类）同时满足持续 150mA 与 350mA 工况。

### 2.1 输出电容稳定性合同（P2 审查补充——真实设计缺口）

AMS1117 系是老式 NPN 差分 LDO，**稳定性依赖输出电容及其 ESR 窗口**，不是"接上就能稳"：

- 现板 +3V3 网络（intent 实测）：C2 = 10µF 陶瓷 + C3/C4 = 100nF×2，合计 ≈10.2µF 陶瓷。
- AMS1117 datasheet 惯例要求输出 22µF 钽电容（或按最新版核对陶瓷可用性），`TO_VERIFY`
  （ECO 冻结 datasheet 后逐页核对稳定性章节：Cout 最小值/ESR 窗口/陶瓷可用性）。
- **ECO 合同新增条款（写入 m2_schematic_semantic_contract 与 intent）**：
  ① U3 输出端须有满足 datasheet 稳定性要求的 Cout（按核对结果定值：现状 10µF 陶瓷若不足
  则 C2 升容或加钽/聚合物电容，BOM 同步）；② transient 响应（WiFi 突发电流）依赖
  Cout+低 ESR，回件 C 级实测项增加"持续 WiFi 负载下 3V3 纹波/跌落"测量。

### 2.2 最低输入工况（P2 审查补充——压差余量不能只按标称 5V 算）

"dropout 1.1V@800mA 满足 1.7V 压差"的表述不严谨，最低输入链路要逐环扣：

- USB VBUS 规格下限 4.75V（端口处）→ 连接器/触点/走线压降（量级 0.05–0.15V，`TO_VERIFY`
  以实板实测为准）→ LDO 输入端 Vin_min ≈ 4.6–4.7V。
- 需求端：Vout + Vdo(@350mA)。AMS1117 dropout 是电流函数（1.1V@800mA、max 1.3V@1A、
  低电流时显著降低），**350mA 处的确切 Vdo `TO_VERIFY`**——冻结 datasheet 的
  dropout-vs-current 曲线读数为准。
- 初判：Vin_min ≈4.6V 对 3.3V+Vdo(350mA)：若 Vdo(350mA) ≤ 1.2V 则余量 ≥0.1V——**薄**，
  必须以曲线实数定案；若不足，缓解项：限制持续负载（占空比）或选低压差同级候选。
- 该项与 1.1 节热分档共同构成 ECO 冻结核对清单的第 1、2 项。

## 3. ECO 影响面（比上次换料大，如实列出）

1. **封装不兼容**：SOT-353 → SOT-223 引脚完全不同（AMS1117：1=GND 2=VOUT 3=VIN tab=VOUT，
   `TO_VERIFY` 冻结 datasheet 核对）——**不是**上次那种逐脚兼容替换，原理图 symbol、PCB
   footprint、逃逸布线、courtyard 全部重做。
2. **board_review 关键字陷阱（PIT 防复发）**：`tools/board_review.py` 的热源/极性/去耦检查
   按 lib_id 关键字识别 U3（上次补过 `SOT-353`）——**换 SOT-223 必须同步补关键字**，
   否则 U3 从三项检查中静默消失（变相放水，禁止）。
3. 全链同步清单（同上次 SOP）：intent → BOM → 原理图 → PCB footprint/布线 → DRC →
   ops 重放 → delivery 重导 → 需求合同重签（语义哈希联动）→ 渲染证据重生成 →
   board_review_auto 重新冻结。
4. U1 datasheet 峰值电流（350mA 量级）以冻结原件核对后回填热核算表。
